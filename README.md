# GNAT-gui

Graphical interface for [GNAT](https://github.com/wrhalpin/GNAT) analyst workflows.

## Modules

- **Analysis** — Investigations, hypotheses with NATO Admiralty Scale scoring, notes, timeline, gap detection, report drafting
- **Rules Builder** — Hy/YAML/Prolog rule authoring with Monaco editor, 26 predicate palette, test runner, promotion workflow
- **Investigations** — Seed-driven evidence graph builder (5-step pipeline), React Flow canvas, node expansion, STIX materialization
